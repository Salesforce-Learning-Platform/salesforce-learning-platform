# Projects

This area contains practical projects built as part of the Salesforce Learning Platform.

Each project should focus on applying concepts learned across Salesforce, frontend engineering, and enterprise architecture.

## Project Categories

- Salesforce Projects
- Lightning Web Components
- Apex Projects
- OmniStudio Projects
- Frontend Projects
- Integration Projects
- Full-Stack Projects
- Architecture Case Studies

## Project Structure

Each project should include:

- Project overview
- Business problem
- Requirements
- Architecture and design decisions
- Implementation details
- Source code
- Setup instructions
- Testing approach
- Key learnings

## Objective

Build a portfolio of practical, production-focused work that demonstrates technical knowledge, implementation skills, and architectural thinking.
