# Frontend Engineering

This module focuses on the foundations and practical skills required to build modern, scalable, and maintainable frontend applications.

## Learning Areas

- HTML
- CSS and SCSS
- JavaScript
- TypeScript
- React
- Vue.js
- Web Components
- UI Architecture
- Design Systems
- Performance
- Accessibility
- Testing

## Objective

Build strong frontend engineering skills through structured learning, practical exercises, reusable components, and production-focused projects.
