# 🖥️ Computer Science Foundations

## 📚 Overview

These sections explain what happens underneath application code. Operating systems come first: how a computer runs many programs, shares memory and processor time, keeps files, and where programs that share data go wrong. Database management systems follow: why databases exist, how data is modeled, and how transactions and indexes keep it correct and fast. Both start from basic Python, and each section has its own page with the question every module answers and what it builds on.
