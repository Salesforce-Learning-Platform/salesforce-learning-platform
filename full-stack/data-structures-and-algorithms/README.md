# 🧩 Data Structures and Algorithms

## 📚 Overview

These modules cover how data can be organized and the algorithms that work on it, from complexity analysis through arrays, hashing, trees, and graphs to sorting, searching, dynamic programming, and tries. Most modules build on several earlier ones, so the order matters. The examples are in Python: you need to be able to read basic Python, while the first module assumes only general programming experience.

## 🧭 The Learning Path

Work through the modules in this order. The last column names the earlier modules each one relies on, so you can also start partway through; links point to modules in other areas.
