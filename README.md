# Salesforce Learning Platform

An open-source learning platform for developers building expertise in Salesforce, frontend engineering, and enterprise architecture.

## What You'll Find

### Salesforce
Practical learning material covering:

- Apex
- Lightning Web Components
- OmniStudio
- Integrations
- Salesforce Development
- Architecture

### Frontend Engineering

Modern frontend concepts and practical development:

- HTML, CSS, and JavaScript
- TypeScript
- React and Vue.js
- Web Components
- Accessibility
- Performance
- Design Systems
- Testing

### Enterprise Architecture

Concepts and practices for designing scalable systems:

- System Design
- Application Architecture
- Integration Architecture
- Data Architecture
- Security
- API Design
- Design Patterns

### Projects

Production-focused projects designed to apply concepts across multiple technologies.

### Resources

Curated references including official documentation, Trailhead content, articles, videos, tools, and open-source repositories.

## Getting Started

Want to start learning right now? The Frontend domain has the most content built out so far —
head to [full-stack/frontend/](full-stack/frontend/) for a "start here" learning path covering
Foundations, HTML, CSS, JavaScript, and TypeScript, in order.
