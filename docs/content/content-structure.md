# Learning Content Structure

## Purpose

This document defines the standard structure used to organize learning material in the Salesforce Learning Platform.

The structure should make it clear how a learner progresses through a topic while allowing individual learning units to be maintained independently.

## Learning Hierarchy

Learning content should follow this hierarchy where applicable:

```text
Learning Area
└── Domain or Subject
    └── Topic
        └── Learning Material
```

In this repository the folders follow the hierarchy. For example, `full-stack/frontend/javascript/functions/closures.md` is learning material in the JavaScript topic of the frontend domain, in the full-stack learning area.
