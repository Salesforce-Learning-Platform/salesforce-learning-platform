# Learning Content Metadata

## Purpose

This document defines the metadata used to describe learning content in the Salesforce Learning Platform.

Metadata provides a consistent way to identify, organize, filter, and connect learning material across the platform.

It is intended to support future platform capabilities without forcing unnecessary complexity into individual learning topics.

## Core Metadata

Where applicable, learning content may include the following information.

### Title

The human-readable name of the learning topic.

The title should clearly describe what the learner will study.

### Learning Area

The broad area to which the content belongs.

Examples include:

- Salesforce
- Full Stack Development
- Architecture
- Computer Science Foundations
- Artificial Intelligence

### Domain

The subject area within a learning area.

For example:

```text
Learning Area: Full Stack Development
Domain: Frontend
Topic: JavaScript
