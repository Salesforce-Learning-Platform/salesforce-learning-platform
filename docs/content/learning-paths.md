# Learning Paths

## Purpose

This document defines the principles used to organize learning content into logical learning paths within the Salesforce Learning Platform.

A learning path connects related topics in a meaningful sequence and helps learners understand where to begin, what to learn next, and which knowledge should be acquired before progressing to more advanced material.

## Learning Path Principles

A learning path should:

- Begin with the knowledge required to understand the subject.
- Progress from foundational concepts toward more advanced application.
- Identify important prerequisites.
- Avoid unnecessary repetition between topics.
- Allow learners to understand the relationship between connected subjects.
- Remain flexible enough to support future expansion.

A learning path should represent a logical progression rather than simply a collection of related topics.

## Typical Progression

Where appropriate, learning material should generally progress through the following stages:

1. **Foundational Knowledge**  
   Introduces essential concepts, terminology, and prerequisites.

2. **Core Understanding**  
   Develops the main knowledge required to work with the subject.

3. **Practical Application**  
   Applies concepts through examples, exercises, implementation, or real-world scenarios.

4. **Advanced Knowledge**  
   Introduces deeper concepts, architecture, optimization, specialization, or complex use cases.

Not every subject requires all four stages as separate sections. The progression should reflect the actual learning requirements of the topic.
