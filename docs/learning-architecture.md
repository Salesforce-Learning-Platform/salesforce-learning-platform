# Learning Platform Architecture

## Purpose

The Salesforce Learning Platform provides structured, practical learning paths for developers who want to build skills in Salesforce development, frontend engineering, and enterprise architecture.

The platform focuses on progressive learning:

Foundation → Core Concepts → Practical Exercises → Real-World Scenarios → Projects

---

# Learning Domains

The platform is organized into three primary learning domains.

## 1. Salesforce

Topics include:

- Salesforce Platform Fundamentals
- Apex
- SOQL and SOSL
- Lightning Web Components
- OmniStudio
- Flows and Automation
- Integrations
- Agentforce
- Security
- Salesforce Architecture

---

## 2. Frontend Engineering

Topics include:

- HTML
- CSS
- JavaScript
- TypeScript
- React
- Vue
- Web Components
- Accessibility
- Performance
- Design Systems
- Testing

## 3. Enterprise Architecture

Topics include:

- System Design

- Observability

---

# Learning Progression

Each learning module should follow a consistent progression.

## Level 1 — Foundation

Learn the terminology, concepts, and basic principles.

## Level 2 — Core Skills

Develop practical understanding through examples and guided exercises.

## Level 3 — Applied Learning

Solve realistic technical problems and implementation scenarios.

## Level 4 — Production Thinking

Understand performance, security, scalability, maintainability, and architecture decisions.

## Level 5 — Assessment

Validate understanding through questions, challenges, debugging tasks, or practical assignments.
