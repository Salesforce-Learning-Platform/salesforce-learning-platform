# Security Policy

## Purpose

Security is an important part of maintaining the Salesforce Learning Platform. We encourage responsible reporting of potential security issues so they can be reviewed and addressed without unnecessarily exposing users, contributors, or project infrastructure.

## Reporting a Vulnerability

If you discover a potential security vulnerability, please do not open a public issue containing sensitive technical details.

Instead, contact the project maintainers privately and include enough information to help reproduce and understand the issue.

Where possible, include:

- A clear description of the vulnerability.
- The affected component, file, or area of the project.
- Steps to reproduce the issue.
- The potential impact.
- Any suggested mitigation or fix, if available.

## Responsible Disclosure

Please allow the maintainers reasonable time to investigate and address a reported vulnerability before publicly disclosing technical details.

We ask security researchers and contributors to avoid actions that could:

- Disrupt the availability of the project or its services.
- Access, modify, or delete data without authorization.
- Expose private contributor or user information.
- Cause unnecessary harm to project infrastructure.

## Scope

This policy applies to security concerns related to the Salesforce Learning Platform repository, its maintained code, documentation, and project-managed infrastructure.

Third-party services, platforms, and dependencies may have their own security policies and reporting processes.

## Updates

This policy may evolve as the project grows and its infrastructure, contribution model, and security requirements become more mature.
