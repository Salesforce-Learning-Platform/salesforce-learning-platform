# Resources

This area contains curated resources that support the learning modules and practical projects in the Salesforce Learning Platform.

## Resource Categories

- Official Documentation
- Trailhead Modules and Trails
- Technical Articles
- Video Tutorials
- GitHub Repositories
- API References
- Design and Architecture Resources
- Development Tools
- Practice Platforms

## Resource Guidelines

Each resource should include:

- Resource name
- Source
- Topic or category
- Relevant learning module
- Brief description
- Why it is useful

## Objective

Maintain a structured collection of reliable learning resources that can support practical learning without duplicating the learning content itself.
